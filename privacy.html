Privacy policy

Effective November 26, 2026.

This static website has no registration, checkout, advertising trackers or analytics scripts. Its hosting provider may process technical request information.

Google Drive

Ezekiel uses Google OAuth and drive.file access to create and verify media output files. This scope also permits access to files explicitly granted to the app. The integration is intended for the business operator.

Credentials are stored in private GitHub Actions secrets. Google and GitHub process data to provide their services. Google Drive data is not sold, used for advertising or used to train AI models.

Files remain in Drive until deleted by the account holder. Access can be revoked through Google Account connections. Contact us for deletion or access questions.

Use of Google API information will adhere to the Google API Services User Data Policy, including Limited Use requirements.
